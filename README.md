# المصحف المرتل — تجويد وحفظ

تطبيق مصحف كامل بألوان التجويد برواية حفص عن عاصم، مع الحفظ والترديد والاختبارات
ودروس التجويد والأذكار ومواقيت الصلاة واتجاه القبلة.

يعمل على **الكمبيوتر (exe)** و**الموبايل (أندرويد / آيفون)** ومن **المتصفح** مباشرة.

---

## المزايا

| # | الميزة | التفاصيل |
|---|--------|----------|
| 0 | **البحث الذكي** | صندوق واحد يفهم ما تكتبه: رقم صفحة/سورة/جزء، أو اسم سورة، أو جزء من آية |
| 1 | **المصحف** | شكل صفحة مصحف حقيقية بإطار مذهّب، اسم السورة والجزء أعلاه ورقم الصفحة في ميدالية |
| 1أ | **تقليب الصفحات** | أسهم ❮ ❯ + أسهم لوحة المفاتيح، وتقليب متتابع عند القفز لصفحة بعيدة |
| 1ب | **القلب التلقائي** | عند انتهاء تلاوة الصفحة تُقلب الصفحة تلقائياً وتستمر التلاوة |
| 2 | **الحفظ** | نطاق بالسورة، بالآيات، **بالصفحة أو عدة صفحات**، بالجزء، بالربع + خيار «إلى آخر السورة» |
| 3 | **الترديد** | تكرار كل آية N مرة، وتكرار النطاق كاملاً M مرة، مع **إيقاف مؤقت واستكمال** |
| 4 | **اختبار الحفظ** | إخفاء النص (تمويه)، واضغط على أي آية لكشفها |
| 5 | **الاختبارات** | ٣ مستويات: سورة / جزء / القرآن كامل — وموضوع: قرآن فقط، تجويد فقط، أو الاثنين |
| 6 | **تنوّع الأسئلة** | التطبيق يتذكّر ما سُئلت عنه، فكل جلسة جديدة تعطي أسئلة مختلفة |
| 7 | **دروس التجويد** | ٩ دروس، وتحت **كل حكم فرعي** آية كاملة من القرآن بالصوت وشرح لموضع الحكم |
| 8 | **القُرّاء** | ١٢ قارئاً منهم **الحصري المعلّم** (تلاوة بطيئة للأطفال والتعليم) — من الشريط العلوي مباشرة |
| 9 | **عند الضغط على آية** | استماع · ترديد N مرة · قراءة التفسير (٥ تفاسير) |
| 10 | **الأذكار** | الصباح (١٤) · المساء (١٣) · النوم (٨) مع عدّاد تكرار |
| 11 | **القبلة والمواقيت** | مواقيت الصلاة والتاريخ الهجري حسب موقعك + بوصلة قبلة + مذهب العصر + تعديل يدوي |
| 13 | **التنبيهات الصوتية** | ينطق «صلاة العصر» أو «أذكار الصباح» عند دخول الوقت مع نغمة وإشعار |
| 14 | **تلميح التجويد** | مرّر الماوس على أي حرف ملوّن ليظهر اسم الحكم فوراً (ويختفي فور الابتعاد) |
| 12 | **الكاش** | يحفظ ما نزّلته فلا يعيد تنزيله، ويعمل بدون إنترنت + زر مسح ظاهر في الشريط العلوي |

## البحث

صندوق البحث أعلى تبويب «المصحف» يفهم ثلاثة أنواع تلقائياً:

| تكتب | تحصل على |
|------|----------|
| `50` | انتقال سريع: 📄 الصفحة ٥٠ · 📖 سورة ق |
| `الكهف` | 📖 سورة الكهف (١١٠ آية) |
| `الحمد لله رب العالمين` | كل الآيات التي تحتوي النص، مع تظليل موضع التطابق |

- **لا حاجة للتشكيل:** اكتب `انا اعطيناك الكوثر` وسيجد `إِنَّا أَعْطَيْنَاكَ الْكَوْثَرَ`
- تختلاف الهمزات لا يهم: `ا` تساوي `أ` و `إ` و `آ`
- اضغط أي نتيجة لينتقل بك للصفحة ويُظلّل الآية
- الكلمات الشائعة جداً (مثل `الله` = ١٩١٩ نتيجة) تُعرض أول ٦٠ نتيجة مع بيان العدد الكلي

> اختيار القارئ ومسح الكاش موجودان في شريط ظاهر أعلى الشاشة في كل التبويبات — لا يوجد تبويب إعدادات.

## ٢) نسخة الكمبيوتر

### أ) ملف التثبيت (Setup) — المفضّل

```
D:\App\quran\installer\output\MushafMurattal-Setup.exe   (١٧.٨ م.ب)
```

اضغط عليه مرتين ليثبّت التطبيق تثبيتاً كاملاً:

| ما يفعله | التفاصيل |
|----------|----------|
| يثبّت البرنامج | `%LOCALAPPDATA%\Programs\MushafMurattal` |
| اختصار قائمة ابدأ | «المصحف المرتل» |
| اختصار سطح المكتب | اختياري أثناء التثبيت |
| إضافة/إزالة البرامج | يظهر باسم «المصحف المرتل ١.٠.٠» |
| إلغاء التثبيت | نظيف تماماً — لا يترك ملفات ولا اختصارات ولا مفاتيح ريجستري |

- **لا يحتاج صلاحيات مسؤول** (تثبيت للمستخدم الحالي)، ويمكن اختيار تثبيت لكل المستخدمين من نافذة المعالج
- المعالج بالعربية والإنجليزية
- يتحقق من وجود **Microsoft Edge WebView2** (المطلوب للعرض) وينبّهك إن كان مفقوداً

**تثبيت صامت** (للتوزيع على عدة أجهزة):
```bash
MushafMurattal-Setup.exe /VERYSILENT /NORESTART /TASKS=desktopicon
```

### ب) النسخة المحمولة (بدون تثبيت)

```
D:\App\quran\dist\MushafMurattal.exe   (١٦.٢ م.ب)
```
افتحه مباشرة — لا يحتاج تثبيت ولا Python ولا أي ملفات بجانبه.

### إعادة البناء بعد أي تعديل
```bash
cd D:\App\quran && python installer/build_installer.py
```
> يبني الـ exe ثم ملف التثبيت معاً.
> يتطلب: `pip install pywebview pyinstaller` و Inno Setup (`winget install --id JRSoftware.InnoSetup`)

## ٣) نسخة الموبايل

### أ) التثبيت الفوري كـ PWA (بدون أي بناء)

شغّل السيرفر على الكمبيوتر بحيث يقبل اتصالات الشبكة:
```bash
cd D:\App\quran && python -m http.server 8000 --bind 0.0.0.0
```
اعرف عنوان جهازك:
```bash
ipconfig | findstr IPv4
```
ثم من متصفح الموبايل (على نفس الواي فاي) افتح `http://192.168.x.x:8000`

- **أندرويد:** قائمة Chrome ⋮ ← «تثبيت التطبيق»
- **آيفون:** Safari ← زر المشاركة ⬆️ ← «إضافة إلى الشاشة الرئيسية»

> ⚠️ العمل بدون إنترنت وتحديد الموقع يحتاجان `https` أو `localhost`.
> عبر `http://192.168...` سيعمل التطبيق لكن قد تُعطَّل هاتان الميزتان.
> الحل: ارفع المجلد على **Netlify** أو **GitHub Pages** (مجاني وبـ https) وثبّته من هناك.

### ب) تطبيق أندرويد حقيقي (ملف APK)

**بدون تثبيت أي شيء على جهازك** — عبر GitHub Actions:

1. ارفع المشروع على GitHub
2. من تبويب **Actions** شغّل **Build mobile apps**
3. حمّل ملف `mushaf-android-apk` من قسم Artifacts
4. انقله للهاتف وثبّته (فعّل «تثبيت من مصادر غير معروفة»)

**أو محلياً** (يتطلب Android Studio + JDK 21):
```bash
npm install
npm run android:add
npm run android:open
```

### ج) تطبيق آيفون (iOS)

> **مهم وصريح:** بناء تطبيق آيفون **مستحيل على ويندوز** — يتطلب جهاز Mac مع Xcode.
> كما أن تثبيته على جهاز حقيقي يتطلب حساب Apple Developer (٩٩$ سنوياً).

الخيارات المتاحة:
- **الأسهل:** استخدم PWA (القسم أ) — يعمل على الآيفون فوراً بدون Mac ولا حساب مطوّر
- **لتطبيق فعلي:** على جهاز Mac:
  ```bash
  npm install && npm run ios:add && npm run ios:open
  ```
  ثم من Xcode: اختر فريق التوقيع واضغط Run

ملف `.github/workflows/build-mobile.yml` يحتوي أيضاً على مهمة iOS تبني المشروع
على macOS في السحابة للتأكد من سلامته (لكنها لا تُنتج ملفاً قابلاً للتثبيت بدون توقيع).

## دقّة مواقيت الصلاة

الفروق بين التطبيقات سببها الإعدادات وليس الحساب. تحقّقتُ من صحّة الحساب الفلكي بمقارنته
بحساب مستقل (غروب القاهرة ١٩:٣١ مطابق تماماً)، والفروق تأتي من:

| السبب | حجم الفرق |
|-------|-----------|
| **طريقة الحساب** (تؤثّر على الفجر والعشاء فقط) | حتى ٢٢ دقيقة للفجر و٢٥ للعشاء |
| **مذهب العصر** (الجمهور مقابل الحنفي) | حوالي ٦٤ دقيقة للعصر |
| الظهر والعصر والمغرب والشروق | لا تتغيّر بتغيّر الطريقة إطلاقاً |

لذلك التطبيق الآن:
1. **يختار الطريقة تلقائياً حسب بلدك** (الإمارات ← الخليج، مصر ← الهيئة المصرية، السعودية ← أم القرى...)
2. يتيح **اختيار مذهب العصر**
3. يتيح **تعديل يدوي بالدقيقة** لكل صلاة (أزرار − و +) لمطابقة مسجدك تماماً
4. يعرض **المنطقة الزمنية والطريقة المستخدمة** أسفل المواقيت لتشخيص أي اختلاف

## التنبيهات

فعّلها من تبويب «القبلة والمواقيت» ← «تفعيل التنبيهات».

- ينطق التطبيق **«حان الآن موعد صلاة العصر»** أو **«حان وقت أذكار الصباح»** بصوت عربي مع نغمة تنبيه
- أذكار الصباح بعد الفجر بـ٢٠ دقيقة، والمساء بعد العصر بـ٢٠ دقيقة، والنوم بعد العشاء بـ٩٠ دقيقة
- يظهر أيضاً كإشعار نظام إن سمحت به

> ⚠️ **حدّ تقني صريح:** يعمل التنبيه ما دام التطبيق مفتوحاً (تبويب في المتصفح، أو التطبيق
> المثبَّت، أو نسخة الكمبيوتر). التنبيه والتطبيق **مغلق تماماً** يحتاج خادم إشعارات
> (Push) أو نسخة أندرويد/iOS الأصلية.
