المصحف المرتل

الوصف القصير (Short description — 80 حرف كحد أقصى):
--------------------------------------
قرآن كريم كامل بتلوين التجويد، حفظ، مواقيت صلاة وأذكار — بدون إنترنت وبدون إعلانات

الوصف الكامل (Full description — 4000 حرف كحد أقصى):
--------------------------------------
المصحف المرتل تطبيق مجاني بالكامل لقراءة القرآن الكريم وحفظه وتعلّم أحكام التجويد، بدون إعلانات وبدون أي اشتراك.

📖 قراءة المصحف
• نص القرآن الكريم كاملاً بخط عثماني واضح، مع تلوين تلقائي لأحكام التجويد (٢٤ حكماً) حرفاً بحرف.
• تصفّح بالسورة أو الجزء أو الحزب، مع بحث فوري في نص القرآن.
• استماع للتلاوة الصوتية بأكثر من قارئ، مع تشغيل متسلسل للآيات.
• وضع القراءة المركّزة (بدون تشتيت) لتجربة أقرب للمصحف الورقي.

🎓 تعلّم التجويد
• 15 درساً تفصيلياً: مخارج الحروف، صفات الحروف، أحكام النون الساكنة والتنوين، أحكام الميم الساكنة، الغنة، أنواع المدود الخمسة، القلقلة، اللام وهمزة الوصل، تفخيم وترقيق الراء ولفظ الجلالة، الإدغام بأنواعه، وأحكام الوقف.
• كل حكم مشروح بمثال حقيقي من القرآن يمكنك الاستماع إليه وترديده.

🧠 الحفظ والمراجعة
• أداة حفظ تفاعلية بالتكرار المتباعد (صفحة أو عدة صفحات، بحسب اختيارك).
• اختبارات (كويز) بمستويات مختلفة: سورة، جزء، أو القرآن كامل — تختبر حفظك للآيات أو أحكام التجويد.

🕌 المواقيت والأذكار
• مواقيت الصلاة الدقيقة حسب موقعك، مع تنبيهات صوتية قابلة للتخصيص.
• اتجاه القبلة.
• أذكار الصباح والمساء والنوم كاملة مع عدّاد تكرار.

✅ بدون إنترنت بعد أول تحميل، بدون إعلانات، بدون حساب أو اشتراك.

تصنيف المحتوى (Content Rating Questionnaire) — الإجابات المتوقعة
====================================================================
التطبيق تعليمي/ديني بحت، لا يحتوي على:
- عنف، محتوى جنسي، ألفاظ نابية، مقامرة، أو مواد خاضعة للرقابة → أجب "لا" على كل هذه الأسئلة.
- لا محتوى ينشئه المستخدمون (لا تعليقات، لا مشاركة).
- النتيجة المتوقعة: تصنيف "للجميع" (Everyone / PEGI 3).

نموذج أمان البيانات (Data Safety form) — الإجابات المطابقة لسياسة الخصوصية
====================================================================
- هل يجمع التطبيق أو يشارك بيانات المستخدم؟ → نعم، بيانات محدودة (الموقع فقط).
- نوع البيانات: Location → Approximate/Precise location.
  - الغرض: App functionality (حساب القبلة ومواقيت الصلاة).
  - هل يُشارك مع طرف ثالث؟ لا (يُرسل فقط لخدمة Aladhan API العامة لحساب المواقيت، ولا يُخزَّن).
  - هل يمكن للمستخدم طلب حذف البيانات؟ لا حاجة — لا يُخزَّن على أي خادم أصلاً.
- هل البيانات مُشفّرة أثناء النقل؟ نعم (HTTPS لكل الطلبات).
- لا توجد بيانات مالية، صحية، أو معرّفات شخصية يجمعها التطبيق.
